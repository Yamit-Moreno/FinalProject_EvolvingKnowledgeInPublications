## 🎯 Goal
Detect and analyze **structural shifts** in large-scale, dynamic networks using **academic citation networks** as a case study, and visualize how research communities evolve over time.

---

## 🧠 Approach (High-level)
- Separate meaningful structural changes from statistical noise  
- Identify communities and track changes over time (merges, splits, emergence of new domains)  
- Visualize temporal evolution using **alluvial diagrams**
