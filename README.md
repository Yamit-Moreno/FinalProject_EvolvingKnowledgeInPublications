This project proposes a framework for analyzing and mapping structural changes in large-scale dynamic
networks, using academic citation networks as a case study, in order to identify patterns and trends in
research communities over time while separating meaningful structural shifts from statistical noise. The
approach combines GraphSAGE-based node embeddings with K-Means clustering, assesses clustering
quality using the Silhouette Score, and visualizes temporal community dynamics—such as merges, splits, and
the emergence of new research domains—through Alluvial diagrams. Overall, the framework enables robust
dynamic network analysis by providing a clear, structured view of network evolution, with potential
applicability to other domains including social networks, transportation systems, biological networks, and
interdisciplinary research.
